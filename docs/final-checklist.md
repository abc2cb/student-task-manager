# Фінальний чекліст Student Task Manager

**Дата перевірки:** 07.11.2026.
**Версія, яку представлено:** розширена версія після самостійної роботи — `server/` на `node:http` і `node:sqlite` з реєстрацією, входом і збереженням даних у SQLite. Статичний MVP практичної роботи №16 (`app/`) залишено в репозиторії як історію.
**Середовище перевірки:** macOS, Node.js v24.21.0, Google Chrome 1280×900, локальний сервер `PORT=3027`, база `server/data/pr17-demo2.db` (файл бази не додається до репозиторію).
**Позначення станів:** «Готово», «Потребує виправлення», «Не застосовується». Пунктів «Не застосовується» немає: усі обов’язкові матеріали створено, а розширені можливості справді працюють.
