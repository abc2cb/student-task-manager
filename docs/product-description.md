# Опис програмного продукту

## Назва

Student Task Manager — навчальний вебзастосунок для обліку навчальних завдань і контролю дедлайнів.

## Проблема

Інформація про завдання часто розподілена між Classroom, чатами, документами та особистими нотатками. Через це студент витрачає зайвий час на пошук актуальної умови, може не помітити зміну строку та не бачить пріоритети всіх робіт в одному місці.

## Цільова аудиторія

Продукт призначений для студентів, які одночасно виконують завдання з кількох дисциплін і хочуть вести єдиний зрозумілий список робіт.

## Мета продукту

Мета Student Task Manager — допомогти користувачеві зібрати навчальні завдання в одному списку, швидко побачити найближчі дедлайни та контролювати статус виконання кожної роботи.

## Основні функції

- додавання завдання з назвою, дисципліною та дедлайном;
- перегляд усіх завдань в одному списку;
- редагування й видалення запису;
- позначення завдання як виконаного;
- фільтрування та сортування завдань за дисципліною, статусом або строком виконання.

## Склад MVP

Мінімальна робоча версія повинна підтримувати створення завдання, введення його назви, дисципліни та дедлайну, перегляд списку, редагування, видалення і зміну статусу на «виконано». Основний сценарій MVP: студент додає роботу, бачить її серед інших завдань, контролює строк і після завершення позначає запис виконаним.

До MVP не входять облікові записи, спільна робота кількох користувачів, хмарна синхронізація, сповіщення та інтеграція з календарем. Ці можливості можуть бути окремими напрямами подальшого розвитку після перевірки базового сценарію.
